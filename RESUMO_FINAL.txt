🚀 COMO FAZER DEPLOY:

git pull origin claude/simple-faq-rag-34uUC

# 2. Deploy no Cloud Run com IAM
./deploy_cloud_run_iam.sh

# 3. Testar endpoint

  --region=us-central1 --format='value(status.url)')
